# our-keeb
This is a hackclub organised program in which we built a fully custom keyboard ourselves. I decided to participate in this program, because I thought it would be a nice easy project, in which I can involve my gf,
and also learn some new skills. And I don't regret this decision! We had so much fun planning our keyboard, learning how to design pcbs in KiCAD and 3D models in Fusion. We managed to design so far a 60%-ish keyboard
with some custom buttons and a rotary encoder, and we're looking foward to bring it to life. At the end of the day I can proudly say, that thanks to this program we're going to make other fun projects together and 
I'm not doing this hobby alone anymore :)

(if you're interested in our work check out the issues, where we documented our "journey" with photos)
